# 🛒 Amazon Best Sellers Parser

Цей проект — веб-додаток для автоматичного збору інформації про топ-5 товарів з категорій **Amazon Best Sellers**.
Рішення розроблено в рамках тестового завдання. Воно включає Back-end на **FastAPI**, парсер на **Selenium** (для імітації дій реального користувача) та Front-end інтерфейс.


## Функціонал

1.  **Парсинг категорій:** Приймає URL будь-якої категорії Amazon Best Sellers.
2.  **Глибокий збір даних:** Скрипт заходить на сторінку кожного товару окремо для отримання детальної інформації.
3.  **Зібрані поля:**
    * `ASIN`, Назва, Позиція в топі (Rank).
    * `Price` (Ціна), `List Price` (Стара ціна), `Discount` (Знижка).
    * `Rating` (Рейтинг), `Reviews Count` (Кількість відгуків).
    * `Is Prime` (Наявність Prime статусу).
    * `Bullet Points` (Основні характеристики товару).
    * `Best Sellers Rank` (BSR з опису).
4.  **Сховище:** Дані зберігаються локально у файл `products.json`.
5.  **Веб-інтерфейс:**
    * Перегляд товарів у вигляді карток.
    * Сортування (за ціною, за рангом).
    * Фільтрація (за мінімальним рейтингом).
6.  **Публічний доступ:** Можливість демонстрації через тунель `ngrok`.


## Методи обходу блокувань (Anti-Bot)

Для забезпечення стабільної роботи та обходу захисних механізмів Amazon реалізовано наступні технічні рішення:

1.  **Browser Automation (Selenium WebDriver):**
    Замість простих HTTP-запитів (`requests`), які Amazon легко блокує, використовується повноцінний браузер Chrome. Це дозволяє виконувати JavaScript, завантажувати динамічний контент та проходити перевірки TLS-відбитків (JA3 fingerprints).

2.  **Приховування автоматизації:**
    Використано аргумент `--disable-blink-features=AutomationControlled`. Це прибирає глобальну змінну `navigator.webdriver`, за якою анти-бот системи найчастіше виявляють роботів.

3.  **Імітація поведінки людини (Human-like Behavior):**
    * **Випадкові затримки (Random Delays):** Між переходами на сторінки товарів додано паузи (`random.uniform(2, 5)` секунд).
    * **Скролінг:** Скрипт імітує перегляд сторінки для підвантаження зображень.

4.  **Realistic User-Agent:**
    Встановлено заголовок `User-Agent` від актуальної версії звичайного браузера Chrome на Windows, щоб запит виглядав легітимним.

5.  **Алгоритм пошуку ціни "Plan B" (Regex):**
    Оскільки Amazon часто приховує ціну в HTML для користувачів з регіонів без доставки (наприклад, Україна), парсер має дворівневу логіку:
    * *Рівень 1:* Перевірка 7+ різних CSS-селекторів.
    * *Рівень 2:* Якщо селектори не спрацювали, застосовується пошук ціни за регулярними виразами (Regex) у всьому тексті сторінки.


## Технологічний стек

* **Мова:** Python 3.10+
* **Web Framework:** FastAPI
* **Parsing:** Selenium WebDriver, BeautifulSoup4
* **Frontend:** HTML5, CSS (Bootstrap 5), JavaScript (Vanilla)
* **Server:** Uvicorn
